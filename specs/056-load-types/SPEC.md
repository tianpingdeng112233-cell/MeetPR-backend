# 056 — 自选重量与自重成为正式负荷类型（跨四端）+ 最低版本强制升级

- **Status**: Ready（2026-10-28 /grill 两轮 10 题，David「确认」）
- **级别 / 节奏**: T2（数据契约 + 迁移 + 四端）/ P1。本仓为契约正典；网页（meetpr-plan-web）、iOS（MeetPR）、安卓（meetpr-rn）各自的卡引用本文，结构与文案转写入卡。
- **起因**: plan-web spec 015 §2.0.4（David 选 1C：只有组×次的行可以发布）受阻——后端每组必须带目标值，现有「自重」靠「`intensity_mode=rpe`、`target_value=10` + `coach_note` 含『自重』」凑出来，David 判定这种凑法是错的。

## 术语（已写入 `CONTEXT.md`）

- **自选重量**：重量模式的一种。只规定组数与次数（可另带 RPE / RIR / % 强度），不规定负荷，学员自己选重量，记录时**必须**填实际重量。
- **自重**：重量模式的一种。不规定外部负荷，学员记录时重量**选填**（额外负重时可记）。

## 2. 数据契约（后端，工程细节由 Opus 定）

- `load_mode` 新增 `free_weight`（自选重量）与 `bodyweight`（自重）。二者都不要求 `target_weight` / `target_pct` / `target_rpe` / `rir_target` 以外的负荷字段；`free_weight` 允许同时带一个强度字段（rpe / rir / pct 三选一，沿用 spec 034 规则），`bodyweight` 同样允许。
- **旧客户端兼容（最低版本提高前）**：响应里 `intensity_mode` / `target_value` 两个旧字段仍按今天的形状给出（旧 iOS 以非空解码）：`bodyweight` 投影为今天的形状（`rpe` / `10` + `coach_note` 带「自重」标记，标记只在投影里出现，库里不存）；`free_weight` 在最低版本提高前不会被创建（网页不开放），故无需投影。最低版本提高后的版本再去掉投影、两字段对这两种模式可为 null（另卡，届时确认）。
- 迁移（号开工现场核实）：放宽 `plan_sets_target_value_check` 与 `intensity_mode` 非空，使 `load_mode IN ('free_weight','bodyweight')` 的行可不带目标值；**回填**：一组的 `coach_note` 命中现有自重标记（与 plan-web `STABLE_ZH.patterns.bodyweight` 同一正则）且 `load_mode IS NULL` 的组 → `load_mode='bodyweight'`，去掉备注里的标记字样（备注只有标记时置 null），旧目标值保留不删（可逆）。迁移前备份受影响行（id + 原 coach_note + 原 load_mode）到一张回滚表。
- **旧写入归一**：已发布的旧网页 / 旧 App 仍会按旧形状写自重（`load_mode` 空 + `rpe`/`10` + 备注标记）。后端写入时识别这一形状，存为 `load_mode='bodyweight'` 并去掉备注标记，与回填口径一致，保证新旧客户端混用期间库里只有一种存法。
- 发布门禁不变（只拦空训练日与零组动作）。
- **最低版本**：新增 `GET /app/min-version?platform=ios|android` → `{ min_build }`（无鉴权、可缓存），值来自 env `MIN_IOS_BUILD` / `MIN_ANDROID_VERSION_CODE`，未配置时为 0（不拦）。

## 3. 各端行为

- **网页编辑器**：重量模式下拉新增「自选重量」（Q10 门控：由后端开关或前端常量控制，最低版本提高前隐藏）。「自重」保存为 `load_mode='bodyweight'`，不再写备注标记、不再写 RPE 10。回读：`load_mode` 优先，旧备注标记仍识别为自重（兼容未回填数据）。只填组×次的行按 Q7 自动归类并视为完整（取代 015 §2.0.4 的草稿实现，分支 `wip/015-reps-only-complete` 作废或改造）。
- **导入（015）**：Q10 门控开启后，「不设重量 / 力竭」归组处理与无负荷的行按 Q7 归类；门控前维持现规则。
- **iOS / 安卓学员端**：读 `load_mode`；`free_weight` 显示「自选重量」，记录时重量必填；`bodyweight` 显示「自重」，重量框显示且选填（取代 iOS 现在隐藏重量框的行为）；强度目标照常显示。旧备注标记兼容识别为自重。
- **iOS / 安卓启动**：读最低版本，低于则整屏阻断页（文案与稿以屏幕稿为准，见 §6）。
