# 繁体中文（台湾用语）适配 — 四端共用规格

- 状态：Ready（2026-10-22 David /grill 共识「确认」）
- 对应编号：iOS/安卓 `094-zh-hant`；后端 `052-zh-hant`；网页 `018-zh-hant`
- 级别：T2（跨仓 + 数据模型加一列），PR 等 David「放行」；发布档 P1
- 来由：台湾外部教练要来内测，他和学员（可能在海外）都用国内版（meetpr.cn）。原则：**不让这位外部教练多做任何事**——不审术语、不改设置、不出特制包。

## 目标
系统/浏览器语言为繁体中文时，教练和学员在网页、iOS、安卓、推送、邮件里看到的全是台湾用语繁体，看不到一个简体字；简体与英文用户零变化。

## 共识（不可在实装中改动）
1. 三端一起：网页编辑器、iOS、安卓；同一个包，不做台湾特制版，不隐藏动作库。
2. 语言判定跟随系统：`zh-Hant*`、`zh-TW`、`zh-HK`、`zh-MO` → 繁体；其余 `zh*` → 简体；非中文按各端现有规则（网页国内域名仍锚定中文，见网页卡）。App 内**不加**语言设置项。网页另支持 `?lang=zh-Hant`（仅测试用）。
3. 文案生成：以现有简体为唯一源，用 OpenCC `s2twp`（简→台湾正体+台湾惯用词）批量生成，再叠加本目录 `GLOSSARY-zh-Hant.md` 的覆写表（覆写优先于 OpenCC）。生成是**开发期脚本**，产物入仓；运行时不带转换库（后端例外见后端卡）。
4. 教练/学员自己输入的内容（计划备注、聊天、自建动作名、昵称）**原样显示**，不转换。
5. 推送、邮件、日报、服务端返回的动作库名称跟随用户语言出繁体。

## 共享契约（四端必须一致）
- **语言标签**：`zh-Hans` / `zh-Hant` / `en`（三值，大小写如此）。
- **客户端→后端**（v2 修订，2026-10-22 收货时改）：三端每个 API 请求（含未登录的注册/找回密码、WebSocket 握手、更新检查）都带自定义头 `X-MeetPR-Locale: <当前界面语言标签>`。**不用 `Accept-Language`**：已发布的 iOS（URLSession）与浏览器会自动发送 `Accept-Language`，若以它为准，老客户端在繁体系统上会收到它不支持的繁体名称/推送，违反后端「不破坏在线客户端」硬规则。
- **后端**：只认 `X-MeetPR-Locale`（值不在三值内则忽略）；已登录请求把它写入 `users.preferred_locale`（值变才写，**不阻塞、不让请求失败**）；推送/日报/邮件按它选文案、出参动作名按它转换。无此头（所有老客户端）→ 行为与现网逐字一致。只修下述一处缺陷。
- **动作库名称**：动作库是简体正典数据，**存储永远简体**；展示时按语言转换（客户端用生成好的对照表，后端在出参时转换）。
- **解析与搜索要两种字形都认**：教练在网页/App 里手打 `臥推 5×3`、`硬舉`、`二頭彎舉` 等繁体，速记解析、动作匹配、动作搜索的结果必须与输入对应简体完全一致；落库的 canonical 名仍是简体。

## 顺带修的缺陷（后端卡）
`src/jobs/push-consumer.ts` 现以 `recipient.phone === null` 推断英文推送。国内版改为邮箱注册（spec 048）后，新注册的国内用户 phone 为空，会收到**英文**推送。改为：先看 `preferred_locale`；为空时按部署默认（国内 zh-Hans、Global 维持原 phone 规则）。

## 验收清单（Opus 收货逐项过，实装方不得自定）
1. 三端在繁体系统/浏览器下逐屏走：登录/注册/找回密码、教练首页、学员列表、计划编辑器（含积木编辑器、视频反馈栏）、学员今日训练、记录一组、历史/进度、个人页、聊天、错误提示与空状态——**零简体字**（脚本扫描 + 截图人眼）。
2. 扫描脚本：对生成的繁体产物跑「简体特有字」检测（字集差：在简体里有、在繁体里不应出现的字），命中数为 0；覆写表里每一条都在产物中生效。
3. 用语抽查：「影片」不是「視頻」、「登入」不是「登錄」、「帳號」、「設定」、「訊息」、「計畫」、「健力」、「臥推/硬舉」、引号用「」。
4. 简体回归：简体系统下三端各取 5 个代表屏，与改前截图逐字一致；英文同理各 2 屏。**带历史的老用户升级后第一屏**（简体）不变。
5. 输入兼容：网页和 App 速记里输入 `臥推 100x5 @8`、`相撲硬舉 3x3`、`二頭彎舉`，解析结果与对应简体输入一致；动作搜索输入「臥推」「硬舉」能搜到卧推/硬拉族；落库名为简体。
6. 推送：语言 zh-Hant 的账号收到的每类推送（聊天、漏练、PR 祝贺、待看视频、绑定请求、后移/撤销、计划更新/发布、教练日报）为繁体；zh-Hans 账号不变；**邮箱注册的国内简体账号收到简体推送**（缺陷修复）。
7. 邮件：繁体浏览器/App 发起的注册验证码、找回密码邮件为繁体。
8. 动作名：繁体下动作库名称在三端和服务端返回的统计/计划里均为繁体；用户自建动作名原样。
9. 日期/星期：繁体下星期显示「週一…週日」，日期格式沿用中文格式。
10. 小组件（iOS Widgets）、iOS 系统权限弹窗文案（InfoPlist）、安卓通知渠道名在繁体下也是繁体。

## 交付红线
- 迁移只**加**可空列 `users.preferred_locale TEXT NULL CHECK (preferred_locale IN ('zh-Hans','zh-Hant','en'))`，无回填（空值=保持现状），不改存量数据语义。
- 简体与英文用户任何可见文案、行为不变。

## Out of Scope
- App 内语言切换设置、香港粤语用字、繁体专属版式调整。
- 用户自写内容的转换（聊天/备注/自建动作）。
- 官网 meetpr-site、BP、宣传海报。
- Global 部署的繁体（契约已兼容，但本次只验国内版）。
- 让外部教练参与审校。
