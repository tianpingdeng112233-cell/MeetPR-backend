## 不转换
- 品牌与专名：MeetPR、微信、App Store、TestFlight。
- 代码标识符、占位符（`%@`、`%lld`、`{name}`、`{{count}}`）——转换后占位符必须逐字一致，脚本要校验。

## 台湾动作写法别名（v2，输入侧）
台湾教练手打的动作名先做繁→简规范化，再按下表匹配到动作库 canonical（简体）。这些是**别名**，加入各端现有动作别名表（iOS `CoachKit/Resources/exercise-aliases.json` 为源，网页 `src/data/exercise-aliases.json` 同步；安卓搜索同口径），不改动作库本身。

| 别名（规范化后简体） | canonical |
|---|---|
| 滑轮下拉 | 高位下拉 |
| 窄卧推 / 杠铃窄卧推 | 窄握卧推 |
| 不碰胸暂停卧推 / 不碰胸暂停1秒卧推 / 不碰胸暂停1秒杠铃卧推 / 不碰胸卧推 | spoto 卧推 |
| 保护杠重启深蹲 / 保护杠重启杠铃深蹲 | 架上(PIN)深蹲 |
| 弹力绳卧推 / 弹力绳杠铃卧推 | 弹力带卧推 |
| 弹力绳相扑硬拉 | 弹力带辅助相扑硬拉 |
| 屈体划船 / 杠铃屈体划船 | 杠铃划船 |
| 杠铃早安 | 早安式 |
| 后脚抬高蹲 / 哑铃后脚抬高蹲 | 后脚抬高分腿蹲 |

- 名称后的括号规格（如「（2cm)」「(2cm)」）匹配时忽略，原文保留在备注/显示中由各端现有规则处理。
- 无把握的不收：「Cable三頭伸展」（过顶还是下压不明）、「槓鈴上斜窄臥推」（库里无窄握上斜）——留给教练自建，不强配。
- 速记/Excel 导入：表头「下數」= 次数列，「教練指示」「反饋備註」= 备注类列；单元格「2下@8。80%」= 2 次、RPE 8、80%。
