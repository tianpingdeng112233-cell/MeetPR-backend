## 背景（真 DeepSeek 实测）

用 spec §6 指定的样表跑两步识别，模型输出有以下错误，且都没有标存疑，学员会照错的日子练或漏掉动作：

- **B1 星期错位**：横向周块（每天占若干列、块首行是当天日期）里，若某天那几列既无内容也没写「休息」，模型按出现顺序给 weekday，后面几天整体前移一天。例：某周表头 B=周一 G=周二 L=周三 Q=周四 V=周五 AF=周日，G 列整列空，模型把 L/Q/V/AF 的内容标成 weekday 1/2/3/5。动作的 `source_cells` 列号是对的。
- **B2 日期**：表头日期是**未设日期格式的 Excel 序列号**（单元格文本 "46195"，应为 2026-06-22），前端只转换了日期格式的格子，模型自行换算出错（outline 给 07-06，第二步各周 start_date 给 08-03/08-31 等互相矛盾）。
- **B3 读歪**：(a) 整周横竖读反：4 个训练日 × 4–5 个动作被返回成 7 天 × 2 个动作；(b) 名字为空、只有组次的追加组行（如 `3*3 | 125*2/110`）被塞进上一动作 note（"追加组：…"），结构化只剩顶组；(c) 更糟的一次把**下一行另一个有名字的动作**（`弹力带卧推 1*3 95`）连同其追加组一起吞进上一动作的 note 和 source_cells，该动作消失。
- **B4** `unreadable` 的 `INVALID_NUMBER` 出现 `detail: { track: 'reps', value: null }`（例：`农夫行走 3×30m`），与 spec 的 track 取值不符，前端只能显示「null 不是有效的数字」。
- **B5** 热身/说明行被当动作返回：`髋开髋 + 主项热身组`（sets 0，组次进 note）、`热身激活`、`努力冲 185+115+220这个成绩`。下游会被自动建成自定义动作，且 0 组行挡发布。

## 目标

在 `parseWeek` 返回之后、路由响应之前加一层**服务端确定性校验与校正**（模型不可信，闸门在服务端，同 `inferred` 的思路），并在输入侧把日期规范化：

1. **序列号转日期（B2）**：发给模型前（outline 与 weeks 两步、header_cells 亦然），把**纯整数文本且在 36526–73050（2000-01-01 … 2099-12-31）之间**的格子转成 ISO 日期文本。只改发给模型的文本，`source_cells` 坐标不变。
2. **星期/日期由表头落地（B1、B2）**：在一周 region 内找「日头格」——文本可解析为日期（ISO / M/D / M月D日）或星期（周一…周日 / 星期X / Mon…Sun）的格子。对每个返回的 day，用其动作 `source_cells` 判断所在日块（横向版式：同列段落；竖向版式：同行段落之后到下一个日头之前），若该日块有日头且推出的 weekday 与模型不同 → **以表头为准改写**；能从日期推出的，周 `start_date` 也以表头为准（该周周一）。推不出时保留模型值。同周 weekday 去重约束仍须成立；校正后若冲突则整周按 `REGION_SUSPECT` 失败。
3. **跨日块 / 吞行检测（B3）**：
   - 一个 day 里的动作若落在**两个及以上**不同日头的日块 → 按日块重新分组到对应 weekday；分不清就整周 `REGION_SUSPECT`。
   - 一个动作的 `source_cells` 覆盖了**另一行的「名字格」**（该行最左侧的非数字、非组次/RPE/日期/星期/休息记号的文本格），且该名字 ≠ 本动作名 → 本动作移入 `unreadable`，`reason: 'OTHER'`，`source_cells` 保留，让教练在原表里看到并改格重识别。
   - 动作 `source_cells` 里出现了不止一个组×次记号（`\d+\s*[*x×]\s*\d+` / `\d+组`），但只结构化了其中一个（note 里出现另一个组次记号）→ 同样移入 `unreadable OTHER`（追加组没结构化）。
   - 提示词同时补一句：名字为空、只有组次的行一律作为**同名的另一个动作**返回，不得写进 note；有名字的行一律是独立动作。
4. **B4**：`INVALID_NUMBER.detail` 的 `track` 只允许 `intensity | weight`；次数读不出改用 `reason: 'OTHER'`（或新增 spec 已有语义内的处理，二选一，写进 JOURNAL）；`value` 必须是原文字符串，取不到原文时不用 `INVALID_NUMBER`。
5. **B5**：`sets === 0` 且（名字含 热身/激活/拉伸/warm 或 无任何组次/数值/unparsed）的动作，不进 `exercises`，移入 `unreadable`（`reason: 'MISSING_SETS'`），由教练在预览里跳过或改格。提示词补「热身、激活、说明句子不是动作」。
