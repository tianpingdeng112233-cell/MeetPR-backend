## 身份、短信与隐私方案

点评身份独立存入 `coach_review_accounts`，没有 app user 外键；同一手机号的 app 管理员登录点评时仍是新的普通点评账号。

使用 `cr_` + 32 字节随机数的 base64url opaque bearer token（256 bit），有效期 30 天，数据库只存 SHA-256 摘要。点评路由只认此格式并查询独立 token 表；现有 app JWT 不被接受。app 的既有 JWT 中间件不认 opaque token，因此点评 token 不能获得任何 app 身份。管理接口仍使用 app 管理员 JWT，并复用 admin router 的实时数据库角色复查；未登录、点评账号、普通 app 账号访问新增管理接口一律 403。

短信调用 `src/services/sms.ts` 的 `sendOtp`，`CoachReviewDeps.sendOtp` 可注入替代实现；测试也通过该共享短信边界替换返回验证码。不传 logger 给占位发送器，避免该发送器记录手机号。当前默认占位验证码为 `000000`，真实短信服务商仍是正式开放前置条件。

- 手机号：国内 11 位 `1` 开头，允许 `+86` 前缀并规范化去除。
- 验证码 6 位、5 分钟有效，单次使用；同号 60 秒冷却，每个上海自然日最多 10 次。
- 同一验证码最多 5 次错误尝试，之后必须重新申请；每日额度与冷却存在数据库中，使用事务和行锁。
- OTP 申请与登录共享每 IP 每分钟 20 次桶，复用 `createGlobalRateLimit`；此外仍受既有全局限流。IP 桶为现有中间件的进程内实现，部署代理须正确传递来源并设置 `TRUST_PROXY`。
- 验证码只存 HMAC-SHA256 摘要，以已有 JWT refresh secret 加域前缀绑定手机号和验证码；没有新增密钥或把密钥写进文件。
- 响应投影不含账号手机号；公开点评也不含账号 ID。昵称禁手机号（含全角数字），正文拦截手机号、微信、QQ、链接与数据库词表。名录公开文本有手机号防护；联系方式配置按任务要求原样返回，管理员应配置适当的公开渠道。
- 昵称 2–16、正文 10–1000 以 Unicode code point 计数，与 PostgreSQL `length(text)` 一致；不以 JS UTF-16 单元计数。
- 删除点评为 `deleted_at` 软删除，原评分和正文保留；同一账号对同一教练至多一条未删除点评，删除后可重新创建。下架教练仅改变状态，恢复后原点评重新可见。

## 完整接口契约

所有请求/响应为 JSON。成功的无内容操作返回 204；其他成功响应如下。ID 为 UUID，日期时间是 ISO 8601 字符串。除注明外，不需要请求体。不支持的字段被 Zod object 去除，不写入数据库。

公共及点评账号接口统一前缀 **`P = /public/coach-reviews`**，官网只反代 `/public/` 即可同域完成浏览、登录和写入。管理前缀 **`A = /admin/coach-reviews`**，由现有管理后台调用。表中的 `P` / `A` 必须替换为完整前缀。

### 公用字段类型

`ListedCoachInput`（提交及管理员编辑的完整字段，PATCH 编辑也须发送全部必填字段）：

| 字段                                  | 类型/约束                                                                    |
| ------------------------------------- | ---------------------------------------------------------------------------- |
| `name`, `nickname`, `gender`          | 必填 string，trim，1–200 UTF-16 单元                                         |
| `douyin_handle`                       | 必填 string，trim、转小写后判重，1–200；只作名录唯一标识，公开响应不返回原号 |
| `douyin_url`                          | 必填 HTTPS URL，host 为 douyin.com 或其子域，最长 1000                       |
| `province`, `city`                    | 必填 string，trim，1–200；存储名原样参与精确筛选                             |
| `gyms`                                | 必填 string[]，1–20 项，每项 trim 后 1–200；无场馆填 `["无"]`                |
| `teaching_mode`                       | 必填：`线下` / `线上` / `线上+线下`                                          |
| `best_total_kg`, `coaching_years`     | 选填非负有限 number 或 null，省略按 null                                     |
| `competition_class`, `certifications` | 选填 string 或 null，非空时 trim 后 1–200；省略按 null                       |
| `equipment`                           | 选填 `无装备` / `单层装备` / `多层装备` 或 null；省略按 null                 |

`ReviewInput`：`overall`, `professionalism`, `communication`, `results`, `value` 均为必填 1–5 整数；`body` 为必填 string，trim 后 10–1000 字符。

`PublicCoach`：`id`, `name`, `nickname`, `gender`, `douyin_url`, `province`, `city`, `gyms`, `teaching_mode`, `best_total_kg`, `competition_class`, `equipment`, `certifications`, `coaching_years`, `status`（固定 `published`）, `created_at`, `updated_at`, `review_count`（number）, `averages`。数值选填项返回 number/null；`averages` 在公开点评 <3 时为 null，否则是 `{overall, professionalism, communication, results, value}`，均为四舍五入一位小数的 JSON number；显示末尾 `.0` 由前端 `toFixed(1)` 处理。

`PublicReview`：`id`, `listed_coach_id`, ReviewInput 的六个字段，`nickname`（作者昵称）, `edited`（boolean）, `created_at`, `updated_at`。不返回 `account_id`、手机号、删除标记。修改排序用 `updated_at`，`edited=true` 时前端显示「已修改」。

`AdminCoach`：ListedCoachInput 全字段加 `id`, `status`（`pending` / `published` / `hidden` / `rejected`）, `rejection_reason`, `submitted_by`, `reviewed_by`, `reviewed_at`, `created_at`, `updated_at`。三个审核/提交 ID 与审核时间、拒绝理由可为 null；`best_total_kg` / `coaching_years` 是 PostgreSQL NUMERIC，管理接口可能为数字字符串或 null（测试适配器可能返回 number），前端按 number/string/null 接收。

`stats` 的总数和分组只含 published 教练；点评总数只含这些教练下未删除点评。隐藏、待审、拒绝的教练及其点评不计数；恢复上线即重新计入。统计在数据库分组后生成省/市结构，不受列表分页影响。

列表 `sort`（063-A2 更新）：

- `most`（默认）：公开点评数降序，同数按最近点评的首次发布时间 `coach_reviews.created_at` 降序，无点评最后；再按姓名、id 升序。
- `top`：只含公开点评 ≥3 条的教练；按未舍入的总分平均值降序，同分按点评数降序，再按 id 升序。响应 `averages` 的既有一位小数展示口径不变。
- `latest`：按最近公开点评的首次发布时间降序，修改不改变顺序；无点评最后，彼此按 `listed_coaches.created_at` 降序。时间相同用收录时间、id 稳定排序。
- 三种排序均只含 published 教练，点评只计未删除项。`total` 应用同样的全部筛选，`top` 同时应用 ≥3 条门槛；`offset` 超出总数时仍返回完整 `total` 与空 `coaches`，无匹配时为 0。非法 `sort` 返回既有 400 `VALIDATION_ERROR`。

不存在或不可公开的教练详情统一 404：`{error:"LISTED_COACH_NOT_FOUND", message:"该教练页面不存在或已下架", contact}`。
