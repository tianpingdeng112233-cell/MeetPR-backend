## 合页与预算规则

页名识别阿拉伯数字形式的「第N周」「Week N」或「第N天」「Day N」「DN」，大小写不敏感，允许共同前缀；只有类型、规范化前缀及表头结构一致才合并。数字序号必须正整数且不重复；按数字顺序排序，随后拼接每页识别出的 weeks 并从零重编 index。没有拆页模式或无法确认结构时独立成 block，不能只凭页名猜测。

表头证据取前四十个非空行中识别到的至少两个列定义（动作、组数、次数、重量、强度、备注及现有常见中英文/繁体标签）。比较标签、列相对位置及表头行顺序；忽略大小写、空格和内容行数造成的表头行距，保留列布局差异。明确参考页名在预算及模型调用前排除；其它有内容的页由模型逐页判断，无训练周者进入 skipped_sheets；空 sheet 按原规则丢弃。

每个候选 block 单独保留其所有页的前四十个非空行，再分配尾行预算。不同 block 不累加表头预算；同一合并 block 内仍共享预算，必留表头独自超限仍回 IMPORT_HEADERS_TOO_LARGE。所有页（包括参考页）的总文本 400k 字符限制保留。truncated_rows 为候选页裁掉行数之和，不把明确跳过的参考页算作裁行。

block 顺序沿输入中首次出现的候选组顺序；id 为本次响应内的 block-1 等稳定序号。独立页 label 为页名，合并页为首尾页名连接。默认选 block 内最新 start_date 最大者；同日期或都无日期取最后一个。顶层 weeks 等于默认 block.weeks；sheet 为该 block 的首个来源页，header_region 为该页表头。跨页客户端应读取每条 region.sheet；不声称未读取该字段的旧客户端能处理多页坐标，单页旧请求及旧字段保持兼容。

按卡片单个 region.sheet 的契约，逐天拆页合成一个 block，但仍保留各页独立的 week 条目并跨页编号，不虚构横跨多个页的矩形，也不拼接跨页坐标。教练换 block 使用同一 import_id，不再调用 outline；每日次数不变，第二步既有八次接口额度仍共享。

## 最终响应示例（全部合成）

```json
{
  "import_id": "00000000-0000-4000-8000-000000000001",
  "sheet": "合成计划甲",
  "header_region": null,
  "weeks": [
    {
      "index": 0,
      "label": "合成周",
      "start_date": null,
      "training_days": 1,
      "region": { "sheet": "合成计划甲", "r1": 2, "c1": 1, "r2": 2, "c2": 3 }
    }
  ],
  "blocks": [
    {
      "id": "block-1",
      "label": "合成计划甲",
      "sheets": ["合成计划甲"],
      "weeks": [
        {
          "index": 0,
          "label": "合成周",
          "start_date": null,
          "training_days": 1,
          "region": { "sheet": "合成计划甲", "r1": 2, "c1": 1, "r2": 2, "c2": 3 }
        }
      ],
      "header_region_by_sheet": { "合成计划甲": null }
    }
  ],
  "skipped_sheets": ["说明"],
  "truncated_rows": 0
}
```

第二步新增请求形式：

```json
{
  "weeks": [
    { "index": 0, "sheet": "合成计划甲", "cells": [[2, 1, "合成动作甲"]] },
    { "index": 1, "sheet": "合成计划乙", "cells": [[2, 1, "合成动作乙"]] }
  ],
  "header_cells_by_sheet": {
    "合成计划甲": [[1, 1, "动作"]],
    "合成计划乙": [[1, 1, "动作名称"]]
  }
}
```

两种表头字段至少提供一种。对应 sheet 的 own entry 优先（空数组也有明确含义）；没有 entry 时回退旧 header_cells，最后为空数组。两种字段均计入总体字符限制。旧请求无需添加 sheet，仍使用旧表头。
