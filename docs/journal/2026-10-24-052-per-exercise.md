## 实现

- 模型适配器与周编排先校验周/天骨架及 index。骨架、JSON、上游错误沿用一次重试；适配器耗尽重试后，外层不会重复重试。
- `validate-exercises.ts` 按动作执行 zod 校验：合格动作保留；失败动作进入周级 `unreadable`，不触发模型重试。全为坏动作时仍返回有效骨架和诊断列表。
- 五种 reason 根据 zod issue 路径生成。两条数值线分别报告组数不匹配；缺名、缺组数和其他错误均有定位。`detail` 无内容时为 null；INVALID_NUMBER 只保留数字标量或纯数字字符串，可能包含单元格文本的非法值返回 null。诊断不携带动作名、备注或 zod 原始消息。
- prompt 和动作 schema 增加 `source_cells`。过滤非法坐标及越界引用后，对合格动作和 unreadable 都返回坐标数组；缺失引用降为 `[]`。
- 当前周请求只带编辑后的 cells，不带 region，现有 DB 也不保存 outline region。因此以该次周 cells 的最小/最大行列界定可引用范围，不纳入 header_cells；允许边界与范围内空格，空 cells 不保留任何引用。此实现没有增加 API 字段、缓存或 DB 存储。
- `inferred` 仍按整周 cells 取证，保留既有日期提示容错及 `PLAN_IMPORT_DEBUG_DIR` raw dump。
