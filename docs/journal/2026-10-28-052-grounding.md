## 实现与规则

- `input.ts`：纯整数文本且在 36526–73050 闭区间内，按 Excel 1900 日期系统转 UTC ISO 日期。outline 在预算裁剪前规范化；weeks 的 cells 与 header_cells 在模型调用边界规范化。保留坐标，不修改原请求；原格仍用于 inferred 证据和错误原文定位。
- `ground-week.ts`：骨架校验和逐动作校验后、inferred 和路由返回前执行。不增加响应字段。
- 日头：完整 ISO、序列日期、有效 M/D 或 M月D日、中文周/星期、英文星期全称或三字母缩写。完整日期推出 weekday 和周一。月日没有年份时，只借本周原格中完整日期对应的周一推导，检查相邻年份以覆盖跨年；没有可靠年上下文则保留模型值，不取模型年份或当前年份猜测。
- **横排**：多个日头同一行，按列排序，从日头列到下一个日头列之前为一个日块，内容不能在日头行之前。空日块仍保留边界，不按有内容的块顺次编号 weekday。
- **竖排**：日头同一列，按行排序，从日头行到下一个日头行之前为一个日块，来源列不能在日头列左侧。单日头视作一个块。输入 cells 不要求已排序。
- 动作及已有 unreadable 的 source_cells 参与归块。单日可唯一定位时校正 weekday，已有诊断跟随校正；没有来源坐标时保留模型提示。发现同一个模型 day 涉及多个块时，要求每个动作/诊断均能唯一归块才重组，并按日块顺序重编 day_index。来源不足、单动作跨块、混杂布局、无法定位的空日/休息日或校正后星期重复/混合空值，返回整周 REGION_SUSPECT。原表的完整日期分属不同周也拒绝。
- **名字格**：每个日块内，每一行最左侧的候选文本格；排除数字/组次、RPE/RIR（含紧连数字）、日期、星期、休息。横排按各自列段独立找最左格，不拿全行第一个名字代表所有天；竖排按行段内各行找。无日头时退回全行。当前动作名字所在行为本行；找不到同名格时使用最早来源行。引用另一行不同名字格即移到 unreadable OTHER，保留全部有效来源坐标。
- 追加组：来源格存在多个组×次/组数标记、这些标记组数总和大于结构化 sets，且 note 中仍包含来源组次标记时，移到 OTHER。比较忽略空白并统一 `*`/`x`/`×`。提示词要求无名字的追加组作为同名另一个动作，有名字的行独立返回。
- B4 选择：非法 reps → OTHER。INVALID_NUMBER 仅允许 intensity/weight，且模型非法字符串必须与引用格原文 trim 后精确相同，返回该原文字符串；找不到对应原文、非字符串等均用 OTHER，不返回 null value。
- B5：sets=0 且名字包含热身/激活/拉伸/warm，优先返回 MISSING_SETS，即使其他字段也坏。其余 sets=0 且无 reps、两条数值线、unparsed 的动作也转 MISSING_SETS；有 unparsed 的普通动作仍保留。note 不视为结构化处方。提示词明确热身、激活、说明句子不是动作。
- 无新增日志、调试转储或存储。既有四个非法数值回归的模型值没有对应原格，期望按卡片改为 OTHER；零组 inferred 哨兵夹具补 unparsed，保持原测试目的。
