## 实现与文件范围

- `src/services/plan-import/prompts.ts`：逐组次数或次数与重量组合不同，按连续相同处方拆成同名动作，段内 sets 为该段组数，保留顺序及 AMRAP 标记；同格不同段可共用来源坐标。
- `ground-week.ts`：对完整的重量×次数写法核对覆盖情况，支持同格 slash 串及分格来源。结构化只覆盖其中一段时仍标 OTHER；完整拆行可共同覆盖同一来源。独立组次格不当重量对；与输出逐组重量及总组数完全一致的重量重复串保留。既有吞行、追加组检查继续执行。
- `model.ts`：仅内部 WeekInput 增加可选 `correction_cells` 坐标列表，不扩展 HTTP 请求／响应格式。
- `parse-weeks.ts`：首次结果完成 validateExercises、groundWeek 后，如含 OTHER，则去重收集这些诊断的来源坐标，对该周纠错一次。仅在新结果 OTHER 更少时采用；同分、更差或纠错抛错均保留第一次结果。正常无 OTHER 的周不重调，原并发上限不变。
- `deepseek.ts`：纠正提示仅新增固定说明和经 SourceCellSchema 验证的坐标；不发送上次模型输出、诊断文本或附加单元格文本。正常周输入仍包含本次请求的源格，纠正前后不变。纠错调用禁用 adapter 的额外错误重试，最多发出一次 provider 请求；首次正常识别仍保留原有失败重试。
- `validate-exercises.ts`：时间区间取下限秒数，完整写法追加到 note，保留已有说明、去重添加 note_fallback。无效区间不通过这一转换。
- `tests/plan-imports.test.ts`、`tests/services/plan-import-deepseek.test.ts` 及本 journal。未改路由、迁移、配置、依赖或网页代码。

纠错复用同一 usage observer，包括被弃用的候选；路由仍只在一次 HTTP 请求开始时 claim 一次额度，因此内部纠错不占八次接口额度，token 照常累计到 plan_import_runs。合成测试走满八次并确认下一次拒绝，同时校验累计用量。

## 时间区间选择

选择卡片允许的**下限秒数＋原文 note＋note_fallback**，不返回秒数上下限格式。只读核对网页 `src/features/plan-editor/reconcile.ts:109` 与 `src/i18n/stable-zh.ts:13`：次数解析返回 reps／repsMax／amrap，没有秒区间单位；裸数字范围可能被当成次数范围。因此服务端明确降级并保存完整原文，避免把秒区间误解释为次数区间。本卡不扩展网页或数据格式，也不宣称网页新增了秒单位支持。
